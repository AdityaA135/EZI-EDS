EZI EDS

AEM EDS Block Generator — Enhanced

Every cell has a variable name + value. DOCX shows only values. JS uses variable names.

How to use this tool

  • Step 1: Make your document in sharepoint/ google drive and author as you want
  • Step 2: Write in same manner variable names in tool table, same variable will be used in Js
  • Step 3: For text, give value "text", for image use "img", this will make Js as per need
  • Step 4: Give full CSS and specific DOM for the block
  • Step 5: Click "Generate Code", copy css and js
  • Step 6: Just replace hardcoded content in JS innerhtml to ${your_variable_name}
  • Step 7: Preview the doc, it should be working fine!!
